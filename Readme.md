# 🏢 Grand Theft Office - 퍼즐 잠입 게임 🕵️‍♂️

## 🎮 게임 소개
**Grand Theft Office**는 사무실을 배경으로 한 **잠입형 퍼즐 게임**입니다.  
플레이어는 보안 시스템을 피해 사무실을 탐색하고, **문제 해결 능력과 전략적 사고**를 활용하여 목표를 달성해야 합니다.

🔹 **퍼즐 해결 & 문서 탈취 미션**  
🔹 **보안 시스템을 피해 몰래 이동**

## 🛠️ 게임 특징
✅ **퍼즐 요소** - 사무실 내 숨겨진 아이템과 힌트 활용  
✅ **인터랙션 시스템** - 컴퓨터 해킹, 문서 수집 등 퍼즐 풀이

---

## 🎮 조작 방법
| 키 | 동작 |
|------|------------------|
| `W, A, S, D` | 캐릭터 이동 |
| `F` | 상호작용 (문 열기, 아이템 획득) |
| `space` | 점프 |
| `좌클릭` | 물건 집기 |
| `우클릭, Q, E` | 물건 회전 |

## **📄 파일 구조**

- **Assets/**: 게임 리소스 (프리팹, 스크립트, 씬 파일 등)
- **Scripts/**: 게임의 주요 C# 스크립트들
- **Scenes/**: 각 레벨을 구성하는 씬 파일들
- **Prefabs/**: 각 오브젝트의 프리팹 모음
